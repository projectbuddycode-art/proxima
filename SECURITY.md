# SECURITY & COMPLIANCE — PROJECT BUDDY CLIENT ACQUISITION OS

## Safety Principles

1. **No Uncontrolled Bulk Spam**:
   - Conservative daily outreach limits (default 10/day).
   - Strict rate limits and opt-out / suppression list handling.

2. **Passive Public Intelligence**:
   - Utilizes public business listings and open web search.
   - No private data scraping, authentication bypass, or fake accounts.

3. **Human Takeover Mandatory**:
   - High-intent responses (INTERESTED, MEETING_REQUEST, PROPOSAL_REQUEST) instantly halt automated messaging.
   - Requires founder takeover for negotiations, contract terms, or pricing commitments.

4. **Truth & QA Verification**:
   - Truth Agent rejects messages containing unverified claims or hallucinated metrics.
   - Every research finding tracks source URL and timestamp.

5. **Local-First Privacy**:
   - SQLite database remains entirely on the local file system.
   - No data sent to third-party cloud LLM providers when using Ollama locally.
