# Truthfulness & Verification — Project Buddy

## Strict QA Rules
- Never fabricate decision-maker names, emails, phone numbers, or titles.
- Never invent metrics, client case studies, or unverified hiring signals.
- If a data point is unavailable or uncertain, mark it explicitly as `UNKNOWN` or frame it strictly as a `HYPOTHESIS`.
- Every message must undergo QA verification before queueing for outreach.
